# CoolReader 1.0.9

Prepared from `feature/performance-improvements` on 2026-11-23.

## Reading and startup

- Open EPUB and FB2 books with less repeated archive and document scanning. Opening a book directly skips the welcome document and avoids enumerating its parent directory.
- Index document positions and ZIP entries; reuse contents page numbers until pagination or entries change. Build FB2 contents paths and ordered-list numbering in one pass.
- Skip offscreen EPUB chapters, FB2 sections and unused text-block geometry during painting. Reuse new page-image sizes and inline frequently used painting operations.
- Cache image metadata and decoded images within a fixed budget; stream embedded FB2 Base64 from stored UTF-8. Resume cache saves between time slices.
- Search the document in one pass. Cache rendered quick-menu icons. Startup tracing is opt-in.
- Apply several default-reader format groups in one operation.

These changes reduce repeated software work. Physical-device speed and battery improvements have not been measured for this release.

## Devices and automatic updates

One ARMv7 softfp Linux package now contains 22 runtime profiles: PB618, PB619,
PB627, PB628, PB629, PB631, PB632, PB633, PB634, PB634K3, PB700, PB700K3,
PB710, PB740, PB740-2, PB740-3, PB741, PB743C, PB743G, PB743K3, PB970 and PB1040.

All profiles are eligible for the shared automatic-update channel on firmware API
6.10 or newer. InkPad 3 Pro model names normalize to alphanumeric OTA identifiers
7402/7403, keeping the descriptor readable by existing shared clients. The legacy
exact-firmware descriptor retains the five firmware-qualified models.

The 17 added profiles remain experimental. Their DPI defaults and portrait/landscape
software rendering are covered by regression checks, but their firmware libraries,
screens, input, lighting and sleep behavior have not been validated individually.
Color readers display grayscale. InkPad One requires a hard-float build; Android
models require an Android application. Unidentified models remain excluded.

## Installation

Install the shared ZIP over USB, or use **Settings → About & updates → Check for
updates** after this release is published. Automatic checks remain optional.
The update flow preserves settings, dictionaries, reading history and custom assets.
Keep a backup before installing an experimental device profile.

## Validation

Release preparation rebuilds the executable, runs all 34 ARM/QEMU regression groups,
and qualifies it against the four pinned additional firmware runtimes (Verse,
Verse Pro, Era and InkPad 4), alongside the Touch HD 3 baseline. Matching build,
source, checksum and qualification reports accompany the package. Completion is
recorded in the release artifact's verification report. No physical-device or
end-to-end deployed OTA acceptance is claimed.
