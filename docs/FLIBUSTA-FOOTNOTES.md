# Flibusta EPUB in-page footnotes (experimental)

This fork recognizes footnotes generated by Flibusta's FB2-to-EPUB converter **without modifying any EPUB files**.

## How it works

After EPUB XHTML fragments are merged and their cross-file links are normalized,
\`crengine/src/epubfmt.cpp\` inspects \`a[class="a"]\` links. A link is considered a
note reference only when:

- Its text is a short numeric or asterisk marker (for example \`[279]\`, \`{1}\`, \`27\`, \`*\`).
- It has a resolved local \`#id\` destination after merging.
- That destination is a non-empty \`span\` or \`p\` element.

The destination receives \`display: block; -cr-hint: footnote-inpage\` as an
inline style. CREngine already understands this hint and handles the page-bottom
placement. All other references, such as a link labelled "Комментарии" to a
whole section of commentary, are left alone. Ordinary FB2 rendering is unchanged.

This is intentionally conservative and does not try to infer every kind of
custom EPUB footnote markup.

## Regression samples

Actual source files were inspected locally (not stored in GitHub):

| Flibusta ID | Book | Expected marked notes |
| --- | --- | ---: |
| 820555 | Tolstoy, *War and Peace* | 999 |
| 113454 | Dante, *Divine Comedy*, Doré illustrations | 1808 |
| 745428 | Pushkin, *Eugene Onegin* (Lotman commentary) | 122 |
| 73239 | Dante, *Divine Comedy*, chapter commentary links | 0 |

Run the GitHub Actions PocketBook build, then test the resulting .app on a real
PocketBook with in-page footnotes enabled.

**Important:** CREngine may reuse the previously parsed/cached book. For the
first test after installing the patched binary, rename the test EPUB or clear
CoolReader's book cache before reopening it.

If a book still does not show page-bottom notes, inspect the EPUB markup and
rendering logs; a successful build alone cannot confirm pagination on-device.

## Safety

Only the EPUB load path is modified. No book files are rewritten, no links are
deleted, and a CSS or CREngine footnotes setting can still suppress footer
display. Restore the original .app to revert on the device.
